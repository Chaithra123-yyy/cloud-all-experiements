# 1. Install VirtualBox / VMware Workstation

## Aim

To install VirtualBox/VMware Workstation and set up a Linux or Windows guest operating system on a host computer.

## Requirements

* Windows host operating system
* VirtualBox or VMware Workstation
* Linux or Windows ISO file
* Sufficient RAM and storage

## Procedure

1. Download and install **VirtualBox** or **VMware Workstation**.
2. Run the downloaded `.exe` installer.
3. Click **Next** on the setup wizard.
4. Accept the default installation components and click **Next**.
5. If a network interface warning appears, click **Yes**.
6. Click **Install** to begin the installation.
7. Wait until the installation is completed.
8. Click **Finish**.
9. Open VirtualBox/VMware Workstation.
10. Create a new virtual machine and install the required Linux or Windows guest OS.

## Result

VirtualBox/VMware Workstation was successfully installed, and a virtual machine can be created to run a guest operating system.
